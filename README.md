# Semantic Enrichment of Historical Content

A semantic HTML project focused on enriching a static document with meaningful and accessible HTML elements. The task includes replacing non-semantic tags with appropriate headings, lists, time, quote, abbreviation, and formatting tags, while preserving the document structure.

## Live Demo
 [Click here to view](https://html-text-elements-b877e4.gitlab.io)

## Key Concepts Applied

- Replaced `<div>` containers with semantically correct heading tags (`<h1>`, `<h2>`, `<h3>`)
- Structured crew-related data into ordered and unordered lists for improved readability
- Used `<time>` with `datetime` attribute to semantically mark historical event timestamp
- Applied `<abbr>` for acronyms like NASA with full form in the title attribute
- Used `<blockquote>` and `<cite>` to semantically mark historical quotes
- Emphasized important textual content using `<em>` and `<i>` where appropriate
- Used `<sup>` for inline references (e.g., footnotes or citations)
